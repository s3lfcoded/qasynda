# Qasynda — переводы тем, кто рядом

Прототип для ITU Hackathon-2026 (кейс Банка ЦентрКредит). Перевод человеку или продавцу поблизости
без QR-кода и реквизитов: получатель открывает «Принять рядом», отправитель видит его в списке и платит.

Близость подтверждается двумя способами:

| Способ | Как работает | Лимит перевода |
|---|---|---|
| Bluetooth | Телефон получателя транслирует одноразовый маяк, телефон отправителя его слышит | 500 000 ₸ |
| GPS | Сервер сопоставляет координаты, радиус 75 м | 50 000 ₸ |

Это учебный симулятор: деньги и пользователи синтетические, к банку он не подключён.

## Состав

- `backend/` — сервер: FastAPI, SQLite.
- `app/` — приложение для Android и iPhone: Flutter.
- `env.sh` — окружение сборки на Windows (Flutter, Android SDK и кэши на диске D).

## Сервер

Развёрнут на Render: https://qasynda-api.onrender.com (бесплатный тариф: засыпает после 15 минут простоя,
первый запрос после сна идёт около минуты; база сбрасывается при перезапуске). Настройки — в `render.yaml`.

Локальный запуск:

```bash
cd backend
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m pytest -q
QASYNDA_SEED_DEMO=1 .venv/Scripts/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

`QASYNDA_SEED_DEMO=1` создаёт трёх учебных пользователей; их номера и PIN-коды лежат в `backend/app/db.py`
(`DEMO_USERS`). `QASYNDA_DB` задаёт путь к базе, `QASYNDA_CORS_ORIGINS` — разрешённые адреса для веб-клиента.

## Приложение для Android (Windows)

```bash
source env.sh
cd app
flutter test
flutter build apk --release --dart-define=QASYNDA_API=https://qasynda-api.onrender.com
```

Готовый файл: `app/build/app/outputs/flutter-apk/app-release.apk`. Адрес сервера можно поменять и в самом
приложении — значок сервера на экране входа. HTTP без шифрования разрешён только в отладочной сборке;
для обычной сборки нужен сервер с HTTPS.

## Приложение для iPhone (Mac)

Нужны Xcode, Flutter и CocoaPods.

```bash
cd app
flutter pub get
cd ios && pod install && cd ..
open ios/Runner.xcworkspace   # выбрать свою команду в Signing & Capabilities
flutter run --release --dart-define=QASYNDA_API=https://АДРЕС_СЕРВЕРА
```

## Как устроена безопасность

- У маяка два одноразовых идентификатора. Первый идёт только по Bluetooth, сервер его никому не выдаёт,
  поэтому предъявить его может лишь тот, кто физически рядом. Второй сервер отдаёт в списке получателей.
- Способ подтверждения близости и лимит определяет сервер, а не приложение.
- Координаты получателя хранятся только в памяти, пока открыт экран приёма, и гаснут через 45 секунд.
  Отправителю показывается расстояние с точностью до 10 м и имя в виде «Нурлан С.».
- Перевод атомарный; повтор с тем же ключом не списывает деньги второй раз.
- PIN-код хранится как PBKDF2-хеш, токен сессии — как SHA-256; пять неверных PIN-кодов блокируют вход на 5 минут.

## Известные ограничения

- GPS-координаты присылает приложение, их можно подделать; поэтому лимит по GPS ниже.
- Bluetooth-маяк можно ретранслировать на расстояние; защита от этого не реализована.
- Библиотека `flutter_blue_plus` бесплатна для учебного и некоммерческого использования;
  для коммерческого продукта нужна платная лицензия или замена.
- Казахские тексты нужно вычитать носителю языка.
