# Qasynda — переводы тем, кто рядом

Прототип для ITU Hackathon-2026 (кейс Банка ЦентрКредит). Перевод человеку или продавцу поблизости
без QR-кода и реквизитов: получатель открывает «Принять рядом», отправитель видит его в списке и платит.

Близость подтверждается двумя способами:

| Способ | Как работает | Лимит перевода |
|---|---|---|
| Bluetooth | Телефон получателя транслирует одноразовый маяк, телефон отправителя его слышит | 500 000 ₸ |
| GPS | Сервер сопоставляет координаты, радиус 75 м | 50 000 ₸ |

Это учебный симулятор: деньги и пользователи синтетические, к банку он не подключён.

## Состав

- `backend/` — сервер: FastAPI, SQLite.
- `app/` — приложение для Android и iPhone: Flutter.
- `env.sh` — окружение сборки на Windows (Flutter, Android SDK и кэши на диске D).

## Сервер

Развёрнут на Render: https://qasynda-api.onrender.com (бесплатный тариф: засыпает после 15 минут простоя,
первый запрос после сна идёт около минуты; база сбрасывается при перезапуске). Настройки — в `render.yaml`.

Локальный запуск:

```bash
cd backend
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m pytest -q
QASYNDA_SEED_DEMO=1 .venv/Scripts/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

`QASYNDA_SEED_DEMO=1` создаёт трёх учебных пользователей; их номера и PIN-коды лежат в `backend/app/db.py`
(`DEMO_USERS`). `QASYNDA_DB` задаёт путь к базе, `QASYNDA_CORS_ORIGINS` — разрешённые адреса для веб-клиента.

### Ограничения

| Что | Правило |
|---|---|
| Вход | 5 неудачных PIN на номер за 5 минут, 15 за сутки; попытка засчитывается до проверки PIN; счётчики трогает только вход с привязанного телефона или с верным кодом из SMS, поэтому чужие запросы не закрывают вход владельцу |
| Вход с одного адреса | 50 неудач за 10 минут — только если задан `QASYNDA_IP_HEADER` (см. ниже) |
| Перевод | от 100 ₸ (как у Банка ЦентрКредит); до 500 000 ₸ по Bluetooth и 50 000 ₸ по GPS |
| За 24 часа | всего 2 000 000 ₸, из них по GPS 150 000 ₸ |
| Частота | 10 переводов в минуту, одному получателю — 3 за 10 минут; отклонённые переводы лимит не тратят |
| Повтор | повтор с тем же ключом сразу возвращает исходный чек, без проверок близости и лимитов: деньги уже ушли |
| Комментарий | до 140 символов Юникода; без ссылок, доменов (в том числе кириллических), @-ников и номеров телефонов; проверка идёт после NFKC, замены похожих кириллических букв и удаления невидимых символов |
| GPS | точка маяка сдвинута на 30 м в случайную сторону, и сравнивается только она; отправителю не сообщается ни расстояние, ни «ближе / дальше»; координаты, до которых нельзя доехать со скоростью 30 м/с, отбрасываются (запас на скачок GPS — раз в минуту); по GPS видно не больше 30 разных людей в час |
| WebSocket | одноразовый пропуск (`POST /ws/ticket`, 30 секунд) проверяется до открытия соединения вместе с сессией, из которой выдан; выход, отвязка устройства и «выйти на всех других» закрывают соединения; до 3 соединений на человека |
| Порядок входа | `POST /auth/start` с номером: с привязанного к этому номеру телефона — сразу PIN (`POST /auth/login`), с нового — SMS, `POST /auth/code`, затем PIN (`POST /auth/confirm`); ответ для несуществующего номера такой же, как для настоящего |
| Новый телефон | код из SMS — 6 цифр, 5 минут, 5 попыток (засчитываются до сравнения); PIN не проверяется, пока код не подтверждён, а `/auth/login` с непривязанного телефона PIN не проверяет вовсе; SMS — 3 в час на номер |
| Регистрация | после верного кода из SMS `POST /auth/code` отвечает `registered`: есть ли аккаунт, сервер говорит только тому, кто доказал владение номером; `POST /auth/register` — имя 2–60 символов (буквы, пробел, дефис), PIN ровно 4 цифры, слабые (0000, 1111, 1234, 4321, 1212…) отклоняются; баланс 0, телефон сразу привязан; запрос входа одноразовый; не больше 30 регистраций в час на сервер и 5 в час с одного адреса (если задан `QASYNDA_IP_HEADER`) |
| Пополнение | учебное, `POST /topup` только со своей привязанной карты и из разблокированной сессии: от 100 ₸ до 500 000 ₸, за 24 часа до 1 000 000 ₸ (лимит считается в той же транзакции, что и зачисление); в истории — «Пополнение с Visa •• 8823» |
| Учебные боты | только при `QASYNDA_SEED_DEMO=1`: «Кофейня Qasynda» оставляет деньги себе, «Алия Бот» через 3 секунды возвращает перевод; в поиске всегда последние (`method: demo`), переводы им — без Bluetooth и GPS, но с лимитами перевода по GPS; `POST /demo/request` — Алия присылает до 20 000 ₸, не чаще 5 раз в час; войти за бота нельзя |
| Устройства | `GET /devices`, отвязать — `DELETE /devices/{id}`, все остальные — `POST /devices/logout-others`; владельцу приходит уведомление о входе с нового телефона |
| Разблокировка | баланс, переводы, поиск и устройства доступны только 5 минут после последнего действия в разблокированной сессии; разблокировать — `POST /auth/unlock` с PIN или с секретом биометрии; после 5 ошибок за 15 минут сессия закрывается |
| Face ID / отпечаток | секрет выдаёт сервер (`POST /auth/bio-key`, только из разблокированной сессии), приложение хранит его в Keychain с `biometryCurrentSet` / Keystore только для сильной биометрии: код телефона его не открывает, новый палец или лицо делают его недействительным |
| Приложение | блокировка при запуске и после минуты в фоне (монотонные часы) закрывает все открытые экраны; суммы, номер и карта скрыты точками; токен хранится «только на этом устройстве»; адрес сервера меняется только в отладочной сборке |
| Bluetooth | метка маяка и `public_id` меняются каждые 30 секунд, прежняя метка принимается ещё 20 секунд, прежний `public_id` — 10 минут; из услышанных меток учитываются 64, приложение шлёт 20 самых сильных |

Телефон узнаётся не по IMEI (приложениям он недоступен ни на iPhone, ни на Android 10+), а по случайному
ключу, который приложение создаёт при первом входе и хранит в Keychain / Keystore. `QASYNDA_SMS_DEMO=1` —
учебный режим: код возвращается в ответе и показывается в приложении плашкой «Учебное SMS».

`QASYNDA_IP_HEADER` — имя заголовка, в котором прокси передаёт настоящий адрес клиента и который клиент
подделать не может. `X-Forwarded-For` на Render для этого не годится: Render дописывает в него свой адрес,
но не стирает присланный клиентом. Без этой настройки ограничение по адресу выключено, работает только
ограничение по номеру.

## Приложение для Android (Windows)

```bash
source env.sh
cd app
flutter test
flutter build apk --release --dart-define=QASYNDA_API=https://qasynda-api.onrender.com
```

Готовый файл: `app/build/app/outputs/flutter-apk/app-release.apk`. Адрес сервера можно поменять и в самом
приложении — значок сервера на экране входа. HTTP без шифрования разрешён только в отладочной сборке;
для обычной сборки нужен сервер с HTTPS.

## Приложение для iPhone (Mac)

Код тот же, что и для Android. Нужны Mac с Xcode и Flutter, iPhone с iOS 15 или новее и Apple ID.

1. Клонировать репозиторий на Mac.
2. Один раз открыть `app/ios/Runner.xcworkspace` в Xcode: Runner → Signing & Capabilities → выбрать Team
   (свой Apple ID) и включить «Automatically manage signing». Если идентификатор `kz.qasynda.qasynda`
   занят, заменить его на свой, например `kz.qasynda.ИМЯ`.
3. Подключить iPhone кабелем, разблокировать, нажать «Доверять этому компьютеру».
   На iOS 16+ включить «Режим разработчика»: Настройки → Конфиденциальность и безопасность.
4. Запустить:

```bash
./scripts/build_ios.sh run
```

5. При первом запуске на телефоне: Настройки → Основные → VPN и управление устройством → доверить
   своему профилю разработчика. Затем разрешить приложению Bluetooth и геолокацию.

С бесплатным Apple ID приложение работает 7 дней, потом его нужно поставить заново; с платным
аккаунтом разработчика — год.

Особенности iPhone, учтённые в коде: по Bluetooth он транслирует только UUID сервиса, поэтому идентификатор
маяка зашит в UUID; системный запрос доступа к Bluetooth появляется при первом открытии «Перевести рядом»
или «Принять рядом»; трансляция идёт, только пока приложение открыто на экране.

## Как устроена безопасность

- У маяка два одноразовых идентификатора. Первый идёт только по Bluetooth, сервер его никому не выдаёт,
  поэтому предъявить его может лишь тот, кто физически рядом. Второй сервер отдаёт в списке получателей.
- Способ подтверждения близости и лимит определяет сервер, а не приложение.
- Координаты хранятся только в памяти. У маяка — точка, сдвинутая на 30 м; маяк гаснет при закрытии экрана
  или через 45 секунд без обновления. Для проверки скорости точная последняя точка помнится не дольше 2 минут,
  на сутки — только квадрат около 1 км. Отправителю показывается «где-то рядом» и имя в виде «Нурлан С.».
- Перевод атомарный; повтор с тем же ключом не списывает деньги второй раз.
- PIN-код хранится как PBKDF2-хеш, токен сессии — как SHA-256; пять неверных PIN-кодов блокируют вход на 5 минут.

## Известные ограничения

- GPS-координаты присылает приложение, их можно подделать; поэтому лимит по GPS ниже.
- Bluetooth-маяк можно ретранслировать на расстояние; защита от этого не реализована.
- Библиотека `flutter_blue_plus` бесплатна для учебного и некоммерческого использования;
  для коммерческого продукта нужна платная лицензия или замена.
- Казахские тексты нужно вычитать носителю языка.
